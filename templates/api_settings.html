Available Endpoints
GET /api/expiration/{app_or_patent_number}
Returns full expiration data for any application or patent number.
POST /api/settings/regenerate
Generates a new API key (admin session required).

🔐 Authentication

All API calls from external tools must include the key as a request header. Browser sessions (logged-in users) are automatically authenticated.

Header name: X-EaseIP-Api-Key
Header value: {{ api_key }}

# Replace 17123456 with your application or patent number curl -k \ -H "X-EaseIP-Api-Key: {{ api_key }}" \ "https://{{ server_host }}/api/expiration/17123456" # By patent number curl -k \ -H "X-EaseIP-Api-Key: {{ api_key }}" \ "https://{{ server_host }}/api/expiration/US11234567"
import requests BASE_URL = "https://{{ server_host }}" API_KEY = "{{ api_key }}" def get_expiration(ref): resp = requests.get( f"{BASE_URL}/api/expiration/{ref}", headers={"X-EaseIP-Api-Key": API_KEY}, verify=False # self-signed cert ) resp.raise_for_status() return resp.json() # Example data = get_expiration("17123456") print(data["effective_expiration"]) # e.g. "2041-03-01" print(data["official_pta_days"]) # e.g. 45
const BASE_URL = "https://{{ server_host }}"; const API_KEY = "{{ api_key }}"; async function getExpiration(ref) { const resp = await fetch( `${BASE_URL}/api/expiration/${ref}`, { headers: { "X-EaseIP-Api-Key": API_KEY } } ); if (!resp.ok) throw new Error(resp.statusText); return resp.json(); } // Example getExpiration("17123456").then(d => { console.log(d.effective_expiration); console.log(d.official_pta_days); });
// Paste into Excel → Data → Get Data → From Other Sources // → Blank Query → Advanced Editor let BaseUrl = "https://{{ server_host }}", ApiKey = "{{ api_key }}", AppNum = "17123456", // ← change this Url = BaseUrl & "/api/expiration/" & AppNum, Response = Web.Contents(Url, [ Headers = [#"X-EaseIP-Api-Key" = ApiKey] ]), Json = Json.Document(Response), Result = Record.ToTable(Json) in Result

⚠ Notes: The server uses a self-signed SSL certificate. External tools will need to disable SSL verification or install the certificate. In Python use verify=False; in curl use -k; in Excel Power Query you may need to configure the data source trust settings. The API is only accessible while the EaseIP server is running on this machine.
